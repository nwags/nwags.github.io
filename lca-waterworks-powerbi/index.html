What this edition does

This report filters and compares 33 prepared division/scenario cases. It does not recalculate arbitrary new assumptions or run a live optimizer. For adjustable planning inputs and the original calculation engine, use the separate JavaScript dashboard.

Know the illustrated account

Bill examples use 5,000 billable gallons per month equivalent, a 5/8-inch meter and one equivalent dwelling unit where applicable. Suburban wastewater uses common rate 1. Actual tariffs and accounts vary; these are model illustrations, not customer quotations.

Evidence, not an official forecast

The evidence cutoff is November 7, 2026. A later report refresh does not change that cutoff. Assumptions and source discrepancies remain visible in the report and model explanation. Passing arithmetic checks is not approval to adopt rates or borrow.

Public and independent

This educational report contains public and synthetic information, not a live Munis or LCA system connection. It is independent of LCA and is also accessible directly through Microsoft’s public link.
